# self-hpo-image-pusher

Mirrors the container images of the deduplicated Self-HPO training pool (2454 tasks) from Docker
Hub into a personal Alibaba Cloud Container Registry (ACR) namespace, so a server in mainland
China without direct Docker Hub access can `docker pull` them over a domestic line.

- `images.tsv`: `<Docker Hub reference>\t<bucket>:<tag>` in download-priority order (initial
  training set first). Generated by the rsicodingagent repository:
  `python -m rsicodingagent.data_prep.images --output-dir DIR` then
  `python -m rsicodingagent.data_prep.acr map --input DIR/images-dockerhub.txt --output images.tsv`.
  Buckets are `<namespace>-<shard>` (shard from the reference's sha256), which keeps the 12
  repositories far below the personal edition's 300.
- `push.sh` / `.github/workflows/push.yml`: 40 jobs (20 at a time) copy their share with
  `crane copy --platform linux/amd64`; images already mirrored are skipped, so re-running the
  workflow only fills gaps. Anonymous Docker Hub pulls are tried first, the account login on
  retries.

Secrets: `ALIYUN_REGISTRY`, `ALIYUN_NAME_SPACE`, `ALIYUN_REGISTRY_USER`, `ALIYUN_REGISTRY_PASSWORD`,
optional `DOCKERHUB_USERNAME`, `DOCKERHUB_TOKEN`.

Run: `gh workflow run push.yml -f limit=10` (trial on the first 10 rows), then
`gh workflow run push.yml` for everything. Per-job results are uploaded as `results-<job>`.
